# PF-RECEIVING-OCR-PR2-20260824

第二個功能 PR 的固定閉環，不得拆成只有照片上傳的半成品：

1. 上傳一張或多張收據照片，保留原始檔與上傳者。
2. OCR 辨識並保存 provider、model、版本、原始輸出與欄位信心值。
3. 整理為逐列可編輯表格，不直接建立正式入庫。
4. 使用者逐欄核對或修正；每次修正保存原值、新值、操作者與時間。
5. 使用者確認入庫後，才建立不可變的收貨與庫存事件。
6. 全程保留原圖、OCR 原始結果、人工修正紀錄與確認入庫 audit log。

本文件不授權在本 PR 實作、部署或修改 OCR、Storage、Edge Function、ERP 或 production schema。
