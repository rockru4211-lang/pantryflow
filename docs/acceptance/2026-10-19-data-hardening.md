# 百花猿資料保存加固（2026-10-19）

## 已實作

- 作業表單暫存後讀回核對；刪除暫存也確認完成，避免瀏覽器靜默失敗卻顯示成功。
- 食譜與價格草稿寫入前比較原始版本，拒絕覆蓋已被另一分頁更新的內容；失敗時保留本頁輸入並顯示警示。
- 損壞的既有草稿不被新建空白內容覆蓋。
- 食譜送出前必須成功保存完整請求與重試識別碼；斷線後沿用原請求，避免重新產生操作。
- 食譜移出門市前，確認本機救援封存已成功保存。
- 暫存失敗時可下載 JSON 救援檔。工作區按鈕保存食譜、版本、未確認請求與已讀到的價格；價格編輯器按鈕另保存該食譜當下尚未寫入裝置的價格。
- 救援檔供後續人工核對復原，不會自動匯入正式資料或覆寫新版本。

## 門市一個月操作配套

1. 每筆作業以系統顯示儲存成功為準；草稿保存與正式儲存分開看待。
2. 出現儲存失敗時保持頁面，使用原頁重試；食譜暫存失敗可先下載救援檔。不要清除瀏覽器資料或另建同一筆單據。
3. 避免同一帳號同時在多個分頁編輯同一份草稿；衝突時保留兩邊輸入，核對後再合併。
4. 每日收班由有權限的人員匯出當日已保存營運表，核對筆數與金額，將原始貨單照片另外留存。
5. 故障紀錄包含門市、操作時間、功能、錯誤文字、單號與截圖；不記錄密碼或 PIN。

## 備份現況與待批准範圍

正式 Supabase 專案健康，方案為 Free。尚未完成獨立的整庫備份、原圖備份或資料庫還原演練，不得宣稱資料絕不會遺失。

整批業務快照遭自動審核拒絕，因涉及多張正式的人員、貨單、成本與營運表，需要用戶明確批准匯出範圍。尚未匯出任何整批業務快照。

準備範圍：BeApe 與 Gras 所屬 BeApe 組織的營運資料及同組織歷史紀錄，排除其他組織、登入憑證、PIN、啟用碼與工作階段。資料表快照並不包含 Storage 原圖或完整登入系統，不能替代完整災難復原備份。

後續步驟：批准範圍後匯出業務資料、記錄筆數與雜湊、另外備份授權範圍的原始檔案，再於隔離環境驗證還原。每日自動備份仍需配置獨立儲存目的地與最小必要權限，不依賴對話持續開啟。

## 驗證邊界

測試使用本機合成資料，覆蓋空間不足、靜默寫入失敗、分頁衝突、損壞草稿、重載後保留請求、雲端成功但本機清理失敗與救援下載。未修改正式業務資料或資料庫結構。

分頁檢查是瀏覽器暫存版本核對，不是跨分頁原子鎖；正式資料仍依賴伺服器權限、版本與冪等控制。裝置損壞、使用者清除瀏覽器或未備份的原圖，不在本次本機草稿保護的保證範圍。
