# 供應商名稱統一維護

使用者確認更新：供應商頁面統一維護系統名稱、公司抬頭及貨單別名。兩店共用同一供應商身份；貨單上的供應商歸屬修正與供應商改名維持原有區分。

## 變更

- 編輯視窗將統一名稱、公司抬頭及貨單別名放在前方；說明改名後顯示同步、舊名保留。
- 既有 `supplier.save` 沿用原權限、版本檢查、冪等請求及稽核。與貨單名稱對應共用組織層級鎖。
- 改名自動保留舊名稱對應，即使之後清空可編輯別名，歷史名稱仍可辨識。停用仍維持停用，不可用於新貨單。
- 新名稱或新增別名若屬於其他供應商（包含停用、移除及已確認對應）會整筆拒絕；不以改名自動合併。已歸併的舊供應商不可由過期頁面直接修改。
- 不改寫原始 OCR、貨單、金額、產品 ID 或供應商外鍵。

## 驗證

- 正式資料庫 migration `20261019093510_supplier_directory_name_updates` 已套用。

- 涵蓋改名／舊名與新別名／貨單、明細、對帳、品項、手機選單讀取／原始紀錄及金額保留／名稱衝突／重試／版本衝突／跨組織／唯讀／角色與停用狀態。
