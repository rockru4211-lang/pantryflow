# 百花猿同門市盤點自動同步

同門市共用盤點資料，前景頁面每 5 秒查詢一次唯讀變更指紋，變更後自動重新讀取；切回 App、視窗取得焦點、網路恢復亦觸發檢查。這是定期同步，非 WebSocket 推播；顯示時間另受網路影響。

- 同步查詢以登入者的有效門市權限檢查，跨店、停用成員與匿名拒絕。沒有開放任何資料表至即時公開訂閱。
- 無變更不重載。查詢序列化；失敗、編輯中或讀取過程被輸入打斷，均不確認該版本，下次恢復可重讀。
- 數量／備註未存、儲存中、輸入框取得焦點、品項編輯、移區對話框、批次選擇及設定表單操作中，延後套用背景資料。既有衝突與重試流程保留，背景不清除未存內容。
- 所有資料取回後才一起套用；背景不切換 busy、不重建盤點、不補建區域。操作途中或切換門市／歷史頁的晚到回應不能套用。
- 品項總覽使用同批取得的資料，保留搜尋狀態；歷史盤點不自動切換到新一期。

驗證：8 項新同步測試通過，包含真正 CountWorkspace 載入函式的輸入途中回應、換頁回應與共同數量更新。相關盤點測試 44 項中 42 項通過；2 項既有 autosave mock 測試失敗名稱與先前基準相同。型別檢查與本次修改檔案 lint 通過；全專案仍有既有 partners-stores-workspace effect lint 錯誤。

`tests/sql/count-store-auto-sync.sql` 在回滾交易中通過：兩位主管共用版本、品項／區域／數量／完成進度／刪除偵測、其他門市無影響、有效 authenticated 呼叫、跨店／停用／匿名拒絕。測試未修改真實門市資料。

發布先套用 `20260924071321_count_store_auto_sync.sql`，再由既有 beape workflow 建置與部署相同提交；正式網站須驗證來源 SHA 與資源圖。
