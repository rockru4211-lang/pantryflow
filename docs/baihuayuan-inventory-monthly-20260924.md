# 百花猿：行政庫存管理定案

2026-09-24 使用者以「定案更新」確認行政端庫存管理畫面。正式來源為 `beape` 分支與 `beape-ops` Worker。

## 操作

- 行政／後勤側欄及首頁新增「庫存管理」，預設進入「總表」。保留「每月抽盤」獨立入口；本次沒有改動公司派發抽盤通知的流程。
- 選擇門市與月份，查看「總表」「差異核對」「庫存金額」。同月有多份已完成盤點時，預設採最近完成的一份，可改選來源。頁面明示以該份盤點範圍為準，不等同尚在變動的即時庫存。
- 總表提供品項／供應商搜尋、儲物區篩選、待核對篩選、每頁 20 項及本頁已計價小計。篩選儲物區時仍顯示品項的跨區合計，避免把篩選後局部數量誤認為全份盤點數量。
- 同品項、同單位合計，展開可看各區原始數量、盤點人員、時間與備註。主管已確認的合計更正只取代原合計一次；不重複相加，也不任意分攤回各區。多筆或跨單位更正不明確時阻擋月份確認。
- 上月依台灣時區的前一個日曆月比較；無前月資料、本月新增、本月未盤或單位變更均明確標示，不把缺資料視為 0、不跨單位相減。
- 使用盤點當時保存的單價。行政補單價只修改本月報表，不改品項現價或原始盤點。缺價項目不計入金額，金額卡與匯出明示缺價數量；兩期有缺價時僅比較已計價小計。
- 非零數量差異、本月未盤、單位變更需核對備註。缺價、來源不完整或未核對事項尚存時，無法「確認本月盤點」。
- 確認後保存該月份數量、價格、明細及備註；後續更名、更正或調價不重算封存金額。下月優先引用已確認的上月資料。
- 匯出 Excel 包含全部總表、資料說明與儲物區原始明細，非僅當頁或篩選結果。數字保持數字；缺資料使用文字，不偽造為 0。

## 資料與權限

新增 `baihuayuan_inventory_month` RPC，動作為 read/review/close/export。只開放對目前 BeApe／Gras 門市具有有效 LOGISTICS／OWNER 身分者。匯出另檢查既有 DATA_EXPORT 權限。STAFF／SUPERVISOR 不取得行政核對或價格報表權限。

`private.inventory_month_reviews` 保存本月核對；`private.inventory_month_closures` 保存封存快照。兩表啟用 RLS，不授予前端直接讀寫；內部來源及狀態函式不授權 authenticated／anon 呼叫。只有檢查身分的私有 definer API 及 public invoker wrapper 開放 authenticated 執行。安全顧問顯示這兩張私有表「啟用 RLS 且無政策」是刻意的預設拒絕設計。

同門市、同月份修改以交易鎖串行處理；每次儲存／確認要求符合最新 revision，舊版本不覆蓋同事的修改。來源數量／價格變更會使原核對失效。月份確認可重試，不重複封存或新增確認稽核。核對與確認均寫入 audit_logs。

頁面前景每 5 秒重新讀取，同時支援重新整理、回到視窗與恢復連線。編輯對話框開啟時暫停背景替換；衝突保留輸入，重新讀取後須重新核對。未儲存內容有離開保護，過期請求不套用到不同月份／門市。
