# 百花猿進貨單 OCR 分工調整

範圍：`beape` 分支、`beape-ops`，正式進貨仍由行政完成核對後發布。

- 員工／主管進入進貨頁、包含舊明細連結，一律顯示上傳與需要重拍清單。上傳完成即可離開，不需檢查 OCR 明細。
- 行政保留既有收件箱與核對工作台，可指定照片與模糊／反光／缺角原因要求重拍。
- OCR 只接受來源照片上明確且高信心的實體缺陷作為自動重拍依據；缺價、缺單號、辨識疑義及服務錯誤交行政處理。PDF 由行政核對。
- 重拍圖片以新路徑保存，接回相同貨單；原始照片、舊辨識結果及修正紀錄保留。全部待補照片上傳成功後，自動排入新辨識工作；重試不新增貨單、工作或庫存。
- 同門市相同原圖集合由資料庫序列化檢查，跨員工與上傳模式自動略過。重新拍攝的貨單，只有可信的供應商／日期／單號與全份標準化內容相同才自動排除；其他情況交行政核對。重複來源與關聯保留供追蹤。
- 待重拍或重新辨識中的貨單不能用舊資料發布。未核對的 OCR 是草稿，不寫入正式庫存或成本。
