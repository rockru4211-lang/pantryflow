# 進貨明細摘要卡定案 — 2026-09-25

依使用者確認的示意圖，將進貨明細上方改為期間／供應商／日期、三張摘要卡、更新資訊及搜尋／狀態，下面保留既有供應商與貨單明細。

- 三卡：所選期間進貨金額（未稅）、不重複貨單數／明細數、待核對項目。
- 全部數字使用目前篩選出的明細；期間標題隨今日、本週、本月、自訂日期變動。
- 金額沿用儲存的未稅金額，不重算原單金額、不推算稅率。缺少數量、單價或金額的項目不計入，顯示未計入項數；全數缺值顯示破折號，空結果或明確零值可顯示零。
- 供應商與單張貨單小計使用相同規則，避免摘要和明細的加總方式不同。
- 待核對卡可切到「需處理」。測試／移出資料保持獨立檢視，不能由卡片不明確切回正式資料。
- 保留上一版讀取防重疊、逾時／重試與匯出失敗保護；載入或讀取失敗時摘要不能顯示零筆。
- 桌面三卡並排；手機金額卡佔一列、兩張數量卡並排。既有外殼、功能權限、原始貨單及庫存資料不變，無資料庫修改。
