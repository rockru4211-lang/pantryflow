# 百花猿手機儲物區視窗

修正手機盤點「儲物區域」視窗被導覽列遮擋，以及長清單讓新增和改名操作離開畫面的問題。

- 使用原生 modal dialog，呈現在捲動容器與導覽列上方，背景不可操作。
- 標題與操作列固定顯示，區域清單獨立捲動；按鈕至少 44px。
- 新增與改名切換至獨立表單，保留原本儲存回呼、權限、衝突提示及失敗草稿。
- 依 visualViewport 高度與位移調整視窗，容納手機鍵盤；關閉後恢復背景捲動與原按鈕焦點。
- 僅修改 CountZonePicker 及其樣式。未更動盤點數量、區域資料或資料庫。

驗證：型別檢查、變更檔 ESLint、來源契約通過。真實 React 元件搭配正式外殼的瀏覽器測試涵蓋 320×568、390×844、844×390、1280×900，25 區長清單、新增、改名、選區、模擬鍵盤、儲存失敗草稿、儲存時 Escape、關閉後焦點和捲動恢復、StrictMode。

既有檢查問題：盤點相關測試 63/65 通過，2 個 autosave harness 測試在修改前的 ba786a0 隔離工作樹同樣失敗。全專案 lint 原有 partners-stores-workspace.tsx:61 的 set-state-in-effect 錯誤與 19 個警告；本次未擴大修改。

手機鍵盤以 visualViewport 事件模擬驗證；仍需使用者在實體 iPhone 上確認鍵盤與安全區呈現。
