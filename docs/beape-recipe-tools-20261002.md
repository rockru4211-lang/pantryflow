# 百花猿：食譜實際用量、匯出與歸屬

## 使用

食材用量採實際單位，可填卷、盒、包、桶等。從公克改成卷時，不沿用原數量，原用量保留在備註，請填實際卷數。價格也改選元／卷；不同單位不會直接沿用原單價。

價格可填每單位金額，或在單位一致且用量已填後，按「改填 2 卷合計金額」。兩卷合計60元會以每卷30元保存；每卷60元則兩卷成本120元。系統不推測使用者原意。整盒使用無須補重量；拆開使用才填每盒可換算多少公克。

食譜與成本頁面上方新增「匯出食譜」「更改歸屬」。匯出可勾選主食譜，附屬配方一併列出且不重複加總。Excel供核對編輯；列印版透過瀏覽器另存PDF，不是直接產生二進位PDF。可不輸出成本欄位，原作法與備註仍保留。

更改歸屬需行政／老闆對來源與目標皆有編輯權限，且屬同商家。先選食譜、新門市，再預覽並確認。主食譜及專用配件移轉，共用配件在新門市另建並重新連結，原店引用不中斷。同名配方不自動合併。新門市原有共用價格不被覆寫，這份食譜保留移轉時採用價格，往後較新的進價／手動價格可更新。
