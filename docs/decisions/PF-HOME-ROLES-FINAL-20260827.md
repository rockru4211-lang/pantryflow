## 四種獨立首頁

1. `STAFF`：綠色員工首頁；今天先看 → 每日作業 → 今日建議 → 商家留言板。
2. `ADMIN`／`SUPERVISOR`：橘色店長／主管首頁；今日重點 → 每日作業 → 需要處理。
3. `LOGISTICS`／`BACKOFFICE`：藍色後勤／管理首頁；今日待核對 → 營運成果 → 管理功能。
4. `OWNER`：紫色 Owner／管理者首頁；營運摘要／重大異常 → 營運成果 → 管理設定。Owner 不進入後勤逐張核對佇列。

後勤與 Owner 不得再被導向店長首頁。Owner 由已驗證的 Owner 身分辨識；其他角色依門市 membership 辨識。

- 頂部顯示門市選擇及通知；後勤與 Owner 另有搜尋。
