## 唯一入口

1. 初始頁只有「員工快速登入」與「管理帳號登入」兩個主要入口。
2. 「建立新商家」是獨立文字入口。
3. 單店與連鎖不分開登入；登入後依實際商家、門市與角色權限顯示內容。

## 員工快速登入

1. 首次流程：門市代碼 → 確認門市 → 該門市固定識別方式 → 確認身分 → 6 位 PIN → 今日工作。
2. 門市只可由主管設定「姓名／暱稱」或「員工編號」其中一種識別方式；員工不可自行切換。
3. 員工不使用 Email、不自行註冊；身分由主管在「設定 → 員工與權限」建立。
4. PIN 連錯 5 次鎖定 15 分鐘；忘記 PIN 由主管重設；停用身分不刪除歷史紀錄。

## 管理帳號與新商家

1. 店長、主管、後勤與 Owner 共用 Email＋密碼登入，實際功能由 membership 權限決定。
2. 新商家流程：建立管理帳號 → 驗證 Email → 建立商家 → 建立第一間門市 → 建立第一位管理者 → 完成 → 管理首頁。
3. 新增員工不屬於註冊流程，不得阻塞商家建立；完成後才由設定頁新增，可稍後處理。

## 記住裝置與重新驗證（2026-08-27 覆寫）

1. 裝置政策由 Owner／主管在「設定 → 登入與裝置」管理；登入者不可自行勾選、切換裝置類型或修改逾期時間。
2. 主管可設定是否允許記住裝置，以及 1 天、7 天（預設）、30 天或每次重新驗證；第一次授權時由主管標記個人／店內共用裝置。
3. 登入頁只顯示唯讀摘要；未獲主管授權的新裝置不得保存門市、Email 或員工身分。
4. 個人裝置記住門市與個人身分；共用裝置只記住門市，每位員工仍需選身分與輸入 PIN。
5. 員工逾時只重新輸入 PIN；管理帳號逾時只重新輸入密碼。
6. 主動登出、身分停用、主管撤銷授權或不受信任裝置才重走完整登入流程。

本節是使用者於 2026-08-27 對定案圖的唯一文字覆寫；定案圖中原本放在 PIN／管理登入畫面的可編輯裝置控制已失效。
