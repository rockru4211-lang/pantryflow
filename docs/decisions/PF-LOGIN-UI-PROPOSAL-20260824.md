## 從三張圖萃取的共通規則

- 色彩：米白頁面底、白色內容面、深森林綠頂欄／主按鈕／主標題；淡綠只用於輔助資訊。
- 字級：頁面主標題約 28–34px；欄位與內文約 13–16px；狀態／說明約 11–13px；資訊層級靠字重與留白，不靠裝飾圖。
- 留白：手機左右 20–24px；區塊垂直間距 16–24px；桌機保持單一閱讀欄，不拉成左右品牌牆。
- 導覽列：深綠水平頂欄、白色文字；登入前不新增底部工作導覽。
- 卡片：白色、細灰綠框、12–20px 圓角、低對比陰影。
- 按鈕：深綠、白字、滿寬、約 52px 高、12px 圓角；次要按鈕為白底細框。
- 響應式：手機維持單欄、欄位滿寬；桌機只增加外圍留白與內容寬度，不改資訊順序、不建立另一套流程。

## 本次提案

- 單一置中的 ADMIN 登入卡，不使用深綠左右分欄品牌卡。
- 只使用 PantryFlow 文字標題，不使用葉子 Logo，也不使用直向身份卡。
- 顯示 Email、Password、登入按鈕與可讀的 inline error。
- 登入後沒有 membership 時，顯示「尚未指派門市」與登出按鈕。
- 不呈現其他角色或功能入口。
