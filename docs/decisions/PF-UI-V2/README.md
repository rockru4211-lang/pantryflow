## 01 登入／註冊／建立門市

### 圖中必備入口、按鈕、文字與流程

- 標題為「PantryFlow｜登入流程定案稿」，並標示「封閉 Pilot」。
- 第一畫面顯示 PantryFlow 品牌與「選擇登入身份」。
- 身分入口依序包含「員工快速登入」、「店長／主管」、「後勤／管理」。
- 員工快速登入先「選擇門市」，再於「選姓名／暱稱」與「輸入員工編號」間選擇識別方式。
- 選姓名／暱稱後，顯示「確認你的身份」清單。
- 選定身分後輸入 6 位 PIN，主要按鈕文字為「登入」。
- 畫面明示「由主管建立帳號與 PIN」及「連續錯誤 5 次將暫時鎖定」。

## 02 進貨

### 圖中必備入口、按鈕、文字與流程

- 標題為「PantryFlow｜進貨人工核對與完成規則」。
- 流程固定為：人工核對・原始單據 → 商品對應與編碼 → 收貨完成。
- 人工核對顯示供應商／收據進度、三張原始單據縮圖及「查看原始收據」。
- 可核對並修正品名 OCR 原文、數量、單價、未稅、稅額及含稅。
- 顯示「需要人工確認」狀態及「下一筆」按鈕；修改需記錄操作者、時間與原始辨識結果。
- 商品對應顯示 OCR 品名與商品主檔的 Mapping，可「選擇既有商品」或「建立新商品／編碼」。
- 核對結果只能選「正確」、「已修正」或「無法判讀」。
- 完成按鈕文字為「儲存並確認收貨」，且每一筆都可回查原始收據。
- 收貨完成依商家設定分流：一般餐廳完成 PantryFlow 核對並收貨結案；已啟用 ERP 驗收的連鎖餐飲顯示「ERP 驗收：待處理」與「明日提醒主管」。
- 畫面明示一般餐廳不會出現 ERP 驗收步驟。

## 03 盤點

### 圖中必備入口、按鈕、文字與流程

- 標題為「PantryFlow｜盤點 Pilot 測試範圍定案稿」，並標示「封閉 Pilot」。
- 原則文字為「員工只盲盤・盤後才出差異・歷史不可覆蓋」。
- 流程固定為：選擇盤點任務 → 選擇區域 → 區域盲盤 → 區域完成 → 全部區域完成 → 盤點差異總覽。
- 任務畫面顯示日期、狀態、區域完成進度、各區項目數及「開始盤點」。
- 選區域畫面顯示今天要盤的區域、項目數、完成狀態及「開始冷藏庫盤點」。
- 盲盤畫面只顯示品名、盤點單位、數字輸入、區域進度及效期提醒；不可顯示上次數量或差異。
- 每輸入一項即自動儲存；完成按鈕文字為「完成此區域」。
- 區域完成畫面顯示勾號、已盤項目數，可「查看已盤清單」或「返回任務」；輸入錯誤須走重盤／更正流程。
- 全部區域完成後才可按「整理盤點差異」。
- 差異總覽只顯示需確認項目，具有「全部／待處理／已處理」篩選、上次／本次／差異、原因選擇及原因快捷選項。
- 原始數量不可直接改寫，必須以更正或重盤事件追加。
- 底部規則包含正式商品與區域、盲盤自動儲存、多區域／批次／狀態、效期提示不干擾、差異原因與 Audit Log、紙本盤點表匯出／回填。
