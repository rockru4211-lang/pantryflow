## 共享資料與權限

- 以門市及單一效期記錄為共同來源；廢棄／使用完的結果唯一且不可覆寫。完成移出所有身份的待處理，歷史及其他批次保留。
- 員工和店長可新增、處理；風險設定只限本店 ADMIN／SUPERVISOR。LOGISTICS／OWNER 依已授權門市唯讀。
- 今日到期只填實際數量與單位，過期另填自由文字延誤原因。延誤稽核內容由後端限制角色，員工端不回傳。
- 新表在 private schema，啟用 RLS 並撤銷前端直接存取；public RPC 為 security invoker，private 實作逐次檢查登入與有效門市角色。私有記錄不可 UPDATE／DELETE。
- 所有寫入以表單 request UUID 防重複；同批次不同人的處理另以 row lock／唯一結果防止重複廢棄。網路重试保留 request UUID；內容改變不會悄悄另建一單。
- 正常風險位置只讀；開啟頁面不留下「已巡查」。異常保留位置快照、回報人及時間。
- 有 ERP 才有公司流程待辦；回報會保存本次開啟的明細集合，新增晚到記錄不會被誤標已輸入。無 ERP 的參考價格只取本店最近已發布且單位一致的進貨單價；缺少價格仍為未提供。
