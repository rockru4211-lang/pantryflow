# 食材基準表第一步：排序與同名紀錄集中

本次只整理既有基準表的呈現，不更換標準進價，不變更資料庫、別名身分或已鎖定食譜。

- 預設請購食材，取來源實際請購日期，由新到舊；未記日期排後，不以匯入時間冒充使用時間。
- 歷史參考：只有歷史食譜來源的資料，並不表示停用。全部仍可查找所有未停用品項。
- 待整理：同名紀錄及尚無請購/純歷史依據的品項。單筆也能開啟既有別名歸屬操作。
- 同名、同單位、同實際規格的資料集中成一組；只去除明確的「原表計價基準」價格註記，保留品牌/容量/年份/加工差異。人工更正別名不自動歸組。
- 組內先展示人工確認列，其次請購列；其餘原列可展開編輯。這是顯示順序，不是重新選價或資料庫合併。
- 搜尋涵蓋所有組內別名及供應商，搜尋時展開命中組；草稿、待補價格與價差篩選保持原有身分。
- 匯出保留每筆原始 ID 和價格，附歸組名稱、來源與日期，不將不同原價合成單價。

後續價格確認、跨店食譜補價、語意別名核對及持久合併是下一步，不能把本次顯示組數當成已完成去重的正式品項數。

驗證：68 項食材/食譜與介面測試通過；包含分組不改價、規格/單位防誤併、來源日期排序、原列展開、歷史查詢、匯入重試與停用品項保護。
