## 程式

- 登入頁提供至少 8–10 字元、長密碼片語、避開常見密碼與避免跨服務重複使用的建議。
- 註冊、新密碼重設及「我的」內的變更密碼，共用本機強度提示（弱／中／強）與改善方式。
- 強度只是建議，不提高既有帳號登入門檻；既有註冊／新密碼至少 8 字元驗證維持原樣。
- 顯示／隱藏仍是 type=button；同一個 input 保留值，切換不送出。
- 評分模組無網路、儲存或紀錄介面；沒有第三方評分服務，也沒有將明文傳入遙測或紀錄。
- 管理帳號變更密碼先核對本人目前密碼，成功後以新密碼重新登入；員工與 PIN 專用身分不增加密碼操作。
