# 簡潔主表與原列更多

本次使用者核准食材基準表、調撥、廢棄的示意圖；明確排除進貨、庫存與食譜成本。

食材基準表：移除來源欄與分頁，主表四欄（名稱、規格／單位、進價、操作）。歷史食材以單一開關顯示，搜尋仍可找歷史別名。更多在原列下方展開供應商、別名、來源日期；歷史來源、同名紀錄、別名歸屬與停用紀錄再按需展開。既有停用原因/恢復理由流程保留，已停用入口在其他操作。批次編輯涵蓋篩選後的主列且保持分頁；儲存略過未修改列，避免無意重寫價格。

調撥與廢棄：OperationsSheet compactDetails 僅由 transfer/waste 啟用，主表合併數量與單位、保留金額，進價/計價規格/經手人/備註收至原列細節。新增、單列及整批編輯沿用原保存、衝突及草稿機制；移除與恢复仍為原本的狀態紀錄，不刪除正式歷史資料。匯入匯出仍使用完整欄位與原始識別碼。沒有新增虛構的修改歷史資料或資料庫介面。

進貨、庫存仍走完整欄位分支；食譜元件未修改。沒有資料庫遷移、批次合併或重新套價。

驗證：102 項相關測試通過；涵蓋兩種版型、細節編輯與原價保留、移除恢復、部分儲存重試、匯入重複防護、歷史搜尋與未修改價格不寫入。型別與 lint 檢查，正式來源建置與部署版本驗證。
