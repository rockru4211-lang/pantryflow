# 共用頁面呈現規格

由 `app/pilot/workspace-standard.css` 管理，掛載於 AppShell 的 `data-workspace-standard` 內容區。登入與列印不套用桌面密度。

- 字體：桌面內文 14px、表頭 13px、頁名 24px；手機輸入 16px。
- 控制項：桌面 40px、手機 44px；圓角 6px、工具間距 8px、區塊間距 12px。
- 分頁：底線選取；狀態篩選保留按鈕群，兩者用途分明。
- 列表：共用表頭、格線、留白、右側操作樣式；保留各業務欄位與資料順序。
- 編輯：簡單資料原列編輯；設備維修／廠商／合約長內容在該筆展開，共用淺底與右上方儲存、取消。
- 短資料使用單行；備註等預設兩行，內容可加高；既有多行聯絡方式不截斷。
- 行政資料批次編輯共用一組儲存全部／取消全部；單筆只在編輯區顯示儲存、取消。
- 各模組適用同一套工具與表格樣式：進貨、庫存、調撥、廢棄、供應商、食材價格、食譜、抽盤、設備、合約、人員管理。
- 貨單圖片核對、食譜配件、手機分區盤點保留專用工作區。共用樣式不得更動資料、價格、計算、權限、存檔與離開保護。
- 新模組優先採既有共用類別／呈現契約；不要再各自設定不同的大按鈕、欄位高度與留白。
