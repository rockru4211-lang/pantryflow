# Receipt OCR benchmark

Customer receipt images and populated ground truth manifests are private test data. Do not commit them.

For every case record:

- upload and OCR run identifiers;
- exact raw text and normalized value per field;
- `TRUSTED`, `REVIEW`, or `UNREADABLE` result;
- arithmetic validation failures;
- human corrections;
- whether a second run preserved the first run.

Milestone 1 is not accepted until the real 2026-08-21 images have been run and reported per image.
